\begin{abstract}
Vision-language-action (VLA) policy 常以 action chunking 分攤昂貴推論成本，但 chunk 後段 action 會在較新的 robot state 下被執行，卻仍然來自較早 observation。本文提出 \method{}，一個窄而可檢驗的介入：凍結針對 LIBERO 適配的 \smolvla{} planner，只訓練小型 wrist-camera residual module 修正當前要執行的 base action。Fast module 使用當前 wrist patch features、proprioceptive state、selected base action、chunk position 與 cached slow-planner context，並透過 $\afinal=\abase+\alpha\,\mathrm{clip}(\deltah)$ 產生 bounded correction。所有 main quantitative claims 只報告 LIBERO-Spatial。在 synchronous plan-50 execution sweeps 中，\method{} 於 $K=2,4,8,16,32,50$ 的成功率為 $79,80,71,75,59,53\%$，\smolvla{} 為 $72,65,60,57,50,40\%$；但 $K=1$ 時 \method{} 為 $75\%$，低於 \smolvla{} 的 $79\%$。在 synchronous matched-chunk sweeps 中，\method{} 自 $K=4$ 起改善 baseline，$K=50$ 為 $53\%$ 對 $40\%$。Residual calibration 顯示 residual authority 必須受限，在 plan-50、exec-8 calibration 中 $\alpha=0.75,\dmax=0.2$ 達到 $41/50$ Spatial successes。最後，planner-delay stress test 顯示 delay $d=1..4$ 時，\method{} 維持 $68,72,68,66\%$ success，而 disable-fast ablation 降到 $64,62,61,56\%$。這些結果支持 \method{} 作為 stale VLA chunks 的 clipped local correction layer，而不是 frequent replanning 或完整 async VLA scheduling 的替代品。
\end{abstract}

\section{Introduction}

大型 robot policy 正逐漸把 language-conditioned task intent、visual grounding 與 continuous action generation 整合在一起。RT-1、RT-2、Open X-Embodiment/RT-X、OpenVLA、Octo、$\pi_0$ 與 \smolvla{} 顯示，pretrained 或 cross-embodiment policy 可以成為廣泛可用的 robot controllers~\citep{brohan2022rt1,brohan2023rt2,openx2024,kim2024openvla,ghosh2024octo,black2024pi0,shukor2025smolvla}。問題在於 deployment timing。Slow policy 若每個 control tick 都重新推論，成本很高；因此許多系統一次輸出 multi-step action chunk，並在下一次 replan 前連續執行多個 actions。

Chunking 會產生 stale-action failure mode。Chunk 的第一個 action 和生成它的 observation 對齊；但後段 action 可能在 gripper、object 或 contact geometry 已改變後才被執行。這在 Spatial manipulation tasks 特別明顯，因為小的 gripper-relative error 就可能造成失敗。Slow planner 仍可能保有正確的 global task intent，但 local action 應該用 wrist 附近的 current evidence 修正。

  \centering
  \includegraphics[width=0.98\linewidth]{figures/fig1_problem_schematic.pdf}

  \label{fig:problem-zh}

\method{} 在受限 contract 下測試這個想法。我們使用針對 LIBERO 適配的 \smolvla{} 作為 frozen planner，cache 其 base actions 與 slow context，並只訓練 wrist residual head。Per-step visual correction signal 來自 wrist camera；但 residual 不是 wrist-only controller，因為它也 condition on $\abase$、chunk position、robot state 與 slow-planner context。它也不是完整 real-time VLA scheduler，而是包在 frozen chunking controller 外的一個 fast local correction module。

目前 first-draft evidence 的範圍刻意保守。Main quantitative claims 只使用 LIBERO-Spatial；Object results 不與 Spatial 合併進 main text。除了 planner-delay experiment 以外，所有 sweeps 都是 synchronous inference；只有 planner-delay sweep 使用 async-timestep inference。Figures 是主要 evidence，compact tables 只提供 exact values。

本文貢獻如下：
\begin{itemize}
  \item 一個基於 LeRobot 的 frozen-\smolvla{} system，包含 trainable wrist-camera residual correction path。
  \item 一個 clipped residual merge：$\afinal=\abase+\alpha\,\mathrm{clip}(\deltah)$，不 fine-tune slow planner、不使用 learned deployment gate，也不加入 contact auxiliary head。
  \item Spatial-only planning/execution sweeps，分開 fixed plan-50 execution 與 matched planning/execution chunks。
  \item Async-timestep planner-delay stress test，顯示 slow chunks late arrival 時 fast residual 可降低 degradation。
\end{itemize}

\section{Related Work}

\paragraph{VLA and generalist robot policies.}
大型 robot policy 包含以 real robot data 訓練的 transformer controllers~\citep{brohan2022rt1}，也包含把 web-scale vision-language models 與 robot actions 共同訓練的 VLAs~\citep{brohan2023rt2,kim2024openvla,black2024pi0,shukor2025smolvla}。Open X-Embodiment 與 DROID 代表 data-scaling 方向~\citep{openx2024,khazatsky2024droid}，Octo 則研究可跨 sensors 與 action spaces 適配的 open generalist policy~\citep{ghosh2024octo}。\method{} 不訓練新的 foundation policy，而是問 frozen VLA chunk 能否被 local correction 改善。

\paragraph{Action chunking and real-time execution.}
Action Chunking Transformers 與 Diffusion Policy 推動了 chunked action generation 與 receding-horizon execution 在 manipulation 中的使用~\citep{zhao2023aloha,chi2023diffusionpolicy}。FAST 研究 high-frequency VLA action sequences 的 action tokenization~\citep{pertsch2025fast}。近期 real-time VLA work 則處理 latency 與 chunk continuity：RTC 在執行當前 chunk 時生成下一個 chunk~\citep{black2025rtc}，VLASH 預測 future execution-time state~\citep{tang2025vlash}，VLA-RAIL 把 asynchronous VLA chunks 連成更平滑的 robot trajectory~\citep{zhao2025vlarail}。\method{} 是 complementary approach：大致保留 scheduling，改為修正當下要執行的 action。

\paragraph{Correction heads and fast-slow policies.}
A2C2 是最接近的 conceptual reference：它使用 latest observation、base action、chunk index 與 base-policy features，對 off-the-shelf VLA chunks 加上 lightweight correction head~\citep{sendai2025a2c2}。其他 fast-slow systems 則把 fast manipulation pathway 整合進較慢的 reasoning 或 foundation-model controllers~\citep{chen2025fastinslow,zou2025duocorefs,xue2025rdp,xie2026dynamicvla}。\method{} 延續 frozen-chunk correction 的精神，但在 \smolvla{}/LeRobot implementation 中隔離出 wrist-centric residual path~\citep{cadene2026lerobot}。在沒有相同 backbone、observation stack、data 與 evaluation scripts 前，本文不宣稱直接優於 A2C2。

\paragraph{Wrist views and dense visual features.}
Wrist 與 egocentric views 對 precision manipulation 提供 local evidence~\citep{jangir2022lookcloser,chuang2024activevision}。DINO、DINOv2、DINOv3 與 dense descriptor analyses 顯示 self-supervised ViT features 可提供 localized visual structure~\citep{caron2021dino,oquab2023dinov2,simeoni2025dinov3,amir2021densevit}。R3M、DINOBot 與 CAGE 等 robot systems 也支持用 pretrained visual features 做 data-efficient manipulation~\citep{nair2023r3m,dipalo2024dinobot,xia2024cage}。\method{} 使用 frozen DINOv3 wrist patches 作為 residual head input：每張 wrist image resize/crop 成 $224\times224$，ViT-S/16 產生 $14\times14=196$ 個 patch tokens，每個 token 為 384 維。這讓 fast head 能以 patch-level wrist evidence 做 correction，而不是只依賴 pooled image embedding；heatmap visualizations 若未搭配 causal ablations，只視為 diagnostics。

\section{Method}

\subsection{Problem Setting}

令 frozen VLA planner 從 observation $o_t$ 與 language instruction $\ell$ 產生 action chunk：
\begin{equation}
  A_t = (a^0_t, a^1_t, \ldots, a^{H-1}_t).
\end{equation}
Execution time 會從 active chunk 選出 base action $\abase \in \mathbb{R}^7$。Correction problem 是：在 slow planner 不變的情況下，根據 current wrist feedback 與 cached context 預測 bounded residual $\deltah\in\mathbb{R}^7$。

\subsection{Frozen Planner and Cached Context}

Slow planner 是針對 LIBERO 適配的 \smolvla{} model，並且在 training 與 evaluation 中保持 frozen。Dataset recording 階段會儲存 planner chunk 中被選出的 base action、chunk position、compact slow-planner context、wrist DINOv3 patch features、robot state、images 與 expert action。Verified cached dataset 包含 1,693 episodes、273,465 frames 與 40 tasks。Fast module 從 cached features 訓練，因此 training 不會更新或重跑 slow planner。若 slow planner 或 feature-extraction contract 改變，就必須重新產生 cache。Implementation identifiers 與 exact field names 列於 Appendix~\ref{app:implementation-reproducibility-zh}。

\subsection{Wrist Patch Features}

HFRVLA 的 fast visual path 使用 wrist camera 作為高頻視覺證據來源，而不是依賴第三人稱影像。Recording/cache 階段會把每張 wrist frame 送入 frozen DINOv3 ViT-S/16 feature extractor，產生 $14\times14=196$ 個 patch tokens，每個 token 維度為 384。DINOv3 在 fast-module training loop 中不更新，也不重跑；訓練讀取的是預先 cache 好的 dense wrist patch descriptors。這讓 trainable parameter budget 集中在 residual head，也固定了 visual features 的來源。

雖然 cached descriptor 在資料中是 token sequence，它仍對應 wrist image 的 spatial grid。Residual head 會把 patch tokens 投影到 hidden width，並用 selected base action、chunk position、robot state 與 slow-planner context 形成的 query 進行 pooling。這個設計讓 wrist branch 保留局部視覺解析度，同時不把它變成完全脫離 slow planner 的 independent controller。下方診斷面板顯示一個例子：第三人稱 RGB、wrist RGB、DINO patch-norm heatmap 與 fast wrist residual cross-attention map。這張面板只用來呈現訊號來源與 spatial correspondence；是否具有 causal necessity 需要 appendix 中列出的 DINO masking / wrist masking ablations 才能判定。

  \includegraphics[width=0.98\linewidth]{figures/fig_dino_cross_attention_example.png}
  \parbox{0.94\linewidth}{\footnotesize\textbf{DINOv3 wrist patch diagnostic panel。}
  Frozen DINOv3 以 $224\times224$ wrist crop 產生 $14\times14$ patch grid，fast residual head 再用 slow-planner context 對 patch tokens 做 cross-attention pooling。Heatmaps 是 qualitative diagnostics，不單獨作為 causal evidence。}

\subsection{Fast Wrist Residual}

Trainable module 接收 current wrist patch features、robot state、$\abase$、chunk position、cached slow-planner context，以及 previous/current training window，並預測當前要執行 action 的 full 7D residual $\deltah$。Deployment 使用：
\begin{equation}
  \afinal =
  \abase + \alpha \cdot \mathrm{clip}(\deltah, -\dmax, \dmax).
  \label{eq:merge-zh}
\end{equation}
目前 paper mainline 刻意排除早期的 learned gate、contact auxiliary objective 與 GRU-centered deployment claim。改善必須來自 residual 與其 conditioning，且 residual authority 需受限。

\begin{figure}[t]
  \centering
  \includegraphics[width=0.98\linewidth]{figures/fig1_solution_schematic.pdf}
  \caption{\method{} 架構圖。Frozen \smolvla{} planner 依 SmolVLA input contract 接收 language、top-view RGB、wrist RGB 與 robot state，經 VLM/action-expert stack 以低頻產生 base action chunks 與 cached slow context；frozen DINOv3 wrist encoder 與 trainable fast residual module 則使用 current wrist feedback、state、chunk context 與 selected base action 預測有界 residual。Final action 由 residual 經 clip 與 scale 後加到 selected base action 形成。}
  \label{fig:method-zh}
\end{figure}

\subsection{Training Objective}

Supervised target 是 expert residual：
\begin{equation}
  \Delta a^* = a_{\mathrm{expert}} - \abase,
\end{equation}
loss 為
\begin{equation}
  \mathcal{L}_{\mathrm{res}} =
  \lVert \deltah - \Delta a^* \rVert_2^2.
\end{equation}
這個 target 很簡單，但有 stale-target 問題：deployment 可能修正較早生成 chunk 的 action，而 training 使用 simultaneous residual。因此 chunk-age targets 被列為 appendix 中的 unfinished work。

\section{Experiments}

\subsection{Protocol}

所有 quantitative claims 都 cross-check against project eval registry，目前 registry 包含 267 registered rows。Main results 只使用 LIBERO-Spatial~\citep{liu2023libero}，seed 42。兩個 synchronous generated-checkpoint sweeps 每列 100 episodes，也就是每個 LIBERO-Spatial task 10 episodes。除非另外說明，trained \method{} policy 的 evaluation 使用 $\alpha=0.5$、$\dmax=0.2$；comparison baseline 是 frozen \smolvla{} planner。

除了 planner-delay experiment 以外，所有 sweeps 都使用 synchronous inference。只有 planner-delay sweep 使用 async-timestep inference。三個 main protocols 如下：
\begin{itemize}
  \item \textbf{Plan-50 execution sweep:} planning chunk size 固定為 50，execution/replan interval $K$ 改變。
  \item \textbf{Matched chunk sweep:} planning、execution 與 replan interval 全部設為 $K$。
  \item \textbf{Async planner-delay sweep:} planning chunk 為 50，execution interval 為 16，async request interval 為 8，artificial planner delay $d$ 從 0 到 4。
\end{itemize}

\section{Results}

\subsection{Synchronous Plan-50 Execution}

Figure~\ref{fig:plan50-zh} 顯示 plan-50 Spatial sweep。\method{} 在 $K=1$ 低於 \smolvla{}（75\% 對 79\%），此時 planner 每步 refresh。當 execution 較低頻後，\method{} 在所有 tested $K$ 都有較高成功率：$K=2,4,8,16,32,50$ 時 \method{} 為 $79,80,71,75,59,53\%$，\smolvla{} 為 $72,65,60,57,50,40\%$。這是 stale-chunk correction claim 的主要 evidence。

\subsection{Synchronous Matched Chunk Sweep}

Figure~\ref{fig:matched-zh} 將 planning、execution 與 replanning 都設為同一個 $K$。結果比 plan-50 sweep 更保守：\method{} 在 $K=1,2$ 輸給 baseline，從 $K=4$ 起開始改善。$K=50$ 時，\method{} 為 53\%，\smolvla{} 為 40\%。此結果支持 local-reflex framing，但也顯示 long-horizon chunking 仍然困難。

\subsection{Residual Scale and Clipping}

Figure~\ref{fig:calibration-zh} 顯示 plan-50、exec-8 setting 的 Spatial residual calibration。最佳 tested setting 是 $\alpha=0.75,\dmax=0.2$，達到 $41/50=82\%$ success。更廣的 calibration evidence 也顯示 residual authority 必須受限：在另一個 plan=exec=replan=50 的 long-chunk Spatial calibration 中，$\dmax=999$ 的 no-limit settings 在 $\alpha=0.5,0.75,1.0$ 時分別降到 16\%、4\%、2\%。因此 clipping 是 method 的一部分，而不是 cosmetic safety setting。

\subsection{Async Planner-Delay Stress Test}

Planner-delay experiment 是本文唯一 async-timestep result。Slow planner 在時間 $t$ 觀察，chunk 在 $d$ 個 control timesteps 後可用，execution 從 chunk index $d$ 開始；fast wrist residual 仍在 current timestep 執行。Figure~\ref{fig:delay-zh} 比較 \method{} 與同一 wrapper 的 disable-fast ablation。$d=0$ 時 disable-fast 較高（68\% 對 64\%）。在 delayed chunks 下，\method{} 於 $d=1,2,3,4$ 維持 $68,72,68,66\%$ success，而 disable-fast 降到 $64,62,61,56\%$。

\section{Discussion}

\paragraph{Why the residual helps stale chunks.}
結果符合 fast local correction story。當 frozen planner 每步 replan 時，base action 已與 current observation 對齊，residual 可能 over-correct。當 active chunk 變舊時，wrist view 提供 base chunk 缺少的 current gripper-relative evidence。因此這不是 universal improvement，而是 regime-specific correction。

\paragraph{Why clipping is central.}
Residual head 預測 full 7D action correction；若沒有 clipping，其 authority 可能超過原本要修正的 local error。Calibration results 顯示 merge rule 是 algorithmic claim 的一部分：fast module 應是 bounded correction layer，而不是 unconstrained replacement action head。

\paragraph{What the async result does and does not prove.}
Async-timestep sweep 在 simulation 中隔離 planner-latency semantics。它尚未證明 real-time deployment on a separate remote slow-planner server，也未涵蓋任意 compute delays。但它顯示，在 $d=1..4$ delays 下，current wrist feedback 可避免 disable-fast ablation 出現的 success degradation。

\section{Limitations}

Main evidence 是 single-seed LIBERO-Spatial simulation。Figures 的 confidence intervals 是 episode-level binomial intervals，不是 multi-seed intervals。Real robot latency、camera calibration、actuation limits、contact dynamics 與 residual cap settings 都可能改變 residual distribution。方法也依賴 cached slow-planner contract：若 slow planner 或 feature extraction 改變，就必須重新記錄 cached base actions 與 context。

Wrist path 是 local。當 wrist camera 看見相關 gripper-relative geometry 時，它能修正 drift；但當 target relation 不在 wrist view 中，它不能取代 global scene understanding。最後，目前 training target 是 simultaneous residual，而非 chunk-age aligned target，因此未來 training 應明確建模 stale base actions。

\section{Conclusion}

\method{} 問的是：凍結的 VLA action chunk 能否透過小型 wrist-camera residual head 變得更 reactive？Spatial-only results 支持一個精確 claim：clipped wrist residuals 在 chunks 變 stale 時有幫助，尤其是 longer execution intervals 與 async planner-delay settings；但當 slow planner 每步 replan 時可能有害。因此 \method{} 最適合被理解為 frozen VLA chunks 的 bounded local correction layer。

  \item \textcolor{red}{Chunk-age/stale-target training}：用 delayed base chunks 訓練 residual targets。
  \item \textcolor{red}{No-residual-clip control sweeps}：把 no-clip controls 擴展到目前 calibration evidence 之外。
  \item \textcolor{red}{Multi-seed confidence intervals}：以多個 seeds 或 task-order variants 重跑 main sweeps。
  \item \textcolor{red}{Causal visual ablations}：wrist mask、third-person mask 與 DINO patch masking。
  \item \textcolor{red}{Direct A2C2 same-backbone comparison}：在相同 \smolvla{} backbone 與 registry 下重現 A2C2。
  \item \textcolor{red}{Real-robot tabletop validation}：在 physical tabletop setup 執行 matched trials。
\end{itemize}
