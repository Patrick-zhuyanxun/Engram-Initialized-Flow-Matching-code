\chapter{研究方法}
\label{ch:method}

\section{系統總覽}

\method{} 的核心問題是：當凍結的 VLA planner 一次輸出多步 action chunk 時，chunk 後段 action 可能已經和目前 wrist observation 不一致；此時能否用一個小型、快速、只針對當前 action 的 residual module 做局部修正。整個系統因此被分成兩條路徑。第一條是 frozen slow planner，負責根據語言、影像與 robot state 產生低頻 action chunk 與 task context。第二條是 trainable fast path，使用目前 wrist camera 的局部視覺證據、robot state、chunk position 與 selected base action，預測一個 bounded 7D residual。

此設計刻意不 fine-tune slow planner。Slow planner 的角色是提供 global task intent、action chunk 與可快取的慢速脈絡；fast module 的角色則是根據當下 wrist evidence 修正即將執行的 action。也就是說，\method{} 不是重新訓練一個完整 VLA，也不是把 wrist camera 變成獨立 policy，而是在 frozen chunking controller 外加上一個局部反應層。

\section{Cached training data and slow-planner context}

訓練 fast residual module 時，本研究不直接把 raw LIBERO observation 丟進 train loop 重新執行 slow planner。相反地，我們先建立一個 cached training dataset：在資料記錄階段執行 frozen planner 與 frozen DINOv3 wrist encoder，並把 fast module 需要的 slow-planner outputs、wrist patch features 與 expert action 一起存下來。這讓後續 training 成為一個乾淨的 supervised residual-learning problem，也避免在每個 training step 重複執行昂貴的 VLA forward。

這個資料設計有兩個重要含義。第一，fast module 學到的是「如何修正 frozen planner 目前要執行的 action」，而不是從頭預測整個 action。第二，slow-planner context 仍然存在於 fast path 中，因此本文不主張 residual 是 wrist-only policy。Wrist camera 提供的是高頻 local evidence；task intent 與 chunk phase 仍由 frozen planner 提供。

\section{DINOv3 腕部 patch features}

Fast visual path 的主要新訊號來自 wrist camera。Wrist view 通常比 third-person view 更接近 gripper、object edge 與 contact neighborhood，因此適合觀察 chunk 後段執行時產生的局部偏差。本研究使用 frozen DINOv3 ViT-S/16 feature extractor，將 wrist image 轉成 $14\times14$ 的 patch grid，共 196 個 patch tokens，每個 token 維度為 384。DINOv3 在 fast-module training 中保持 frozen；training 讀取的是已經 cache 好的 dense wrist descriptors。

DINO features 在本文中的角色有三點。第一，它們提供 frozen dense visual representation，降低 fast module 訓練成本。第二，patch tokens 保留 wrist image lattice，適合表示 gripper tip、object edge 與 contact neighborhood。第三，DINO visualization 只用於 pipeline inspection；它不能單獨證明模型決策的因果來源。若要支持 causal claim，仍需要 masking 或 ablation experiments。

\section{Fast residual module}

Fast residual module 的輸入包含 wrist patch features、robot state、selected base action、chunk position、cached slow-planner context，以及 previous/current training window。輸出為 7 維 residual $\deltah$，對應 LIBERO action space 的各自由度。直覺上，selected base action 提供 slow planner 原本想做的動作，wrist features 提供目前 gripper-relative evidence，而 chunk position 告訴 fast module 此 action 在 chunk 中的時間位置。

部署時，模型不直接把 residual 當成完整 replacement action。相反地，\method{} 使用 clipped and scaled merge：

\begin{equation}
  \afinal =
  \abase + \alpha \cdot \mathrm{clip}(\deltah, -\dmax, \dmax).
  \label{eq:thesis_merge}
\end{equation}

其中 $\alpha$ 與 $\dmax$ 控制 fast path 的 residual authority。這兩個參數不是 cosmetic safety settings，而是方法的一部分：如果 residual 權限太大，fast path 可能覆蓋 slow planner 的 global intent；如果 residual 權限太小，則無法修正 stale chunk 的局部偏差。

\section{Training objective}

訓練目標採用 simultaneous residual supervision。對每個 timestep，expert action 與 frozen planner base action 的差值定義為 residual target：

\begin{equation}
  \Delta a^\star_t = a^{expert}_t-a_{\mathrm{base},t}.
  \label{eq:target_delta}
\end{equation}

Fast module 以 residual prediction loss 逼近 $\Delta a^\star_t$。這個 objective 的好處是簡單、穩定，並直接對應到部署時的 additive correction。它的限制也很清楚：training target 使用的是同時間點的 base action，但 long-chunk deployment 中，正在執行的 base action 可能來自較早 observation 產生的 chunk。因此，未來更合理的 target 是 chunk-age 或 stale-target supervision：

\begin{equation}
  \Delta a^\star_{t,k}=a^{expert}_t-a^{base}_{t-k,k}.
\end{equation}

這項限制不影響本文主要結論，因為本文的實驗正是在受控 chunk protocol 下測試目前 residual objective 的有效區間；但它指出了下一步改進方向。

\section{Implementation boundary}
