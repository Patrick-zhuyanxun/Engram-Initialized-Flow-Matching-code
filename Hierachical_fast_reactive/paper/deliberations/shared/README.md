# Shared Deliberations

Use this folder for research records that apply to more than one paper target.
Target-specific debates and reviewer rounds belong under
`paper/deliberations/<target_name>/`.

## Subfolders

| Folder | Purpose |
|---|---|
| `literature_searches/` | Search strategies, database/tool outputs, screened papers, and rejected papers. |
| `citation_audits/` | DOI/arXiv/CrossRef/publisher verification logs and BibTeX integrity checks. |
| `claim_audits/` | Checks that manuscript claims are supported by local results, references, or implementation artifacts. |
| `decision_logs/` | Durable decisions after comparing reviewer, skill, or subagent positions. |

Every note should state the date, tool/skill/source used, reviewed inputs,
decision, and remaining risk.
