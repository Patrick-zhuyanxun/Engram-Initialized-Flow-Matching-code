# NYCU Thesis Deliberations

Use this folder for review and debate material that only applies to the NYCU
master's thesis target.

## Subfolders

| Folder | Purpose |
|---|---|
| `review_rounds/` | Existing reviewer/writer rounds and thesis-level critique passes. |
| `writer_reviews/` | Manuscript-writing critiques, chapter rewrites, and structure reviews. |
| `methodology_reviews/` | Method-specific reviews, especially DINO, residual merging, frozen planner, and dataset details. |
| `rebuttal_plans/` | Planned responses to advisor, committee, reviewer, or defense comments. |
| `revision_logs/` | What changed in each thesis revision and why. |

Distill accepted decisions into `paper/targets/nycu_thesis/source_map.md`,
`paper/targets/nycu_thesis/research_process.md`, or the buildable LaTeX source.
