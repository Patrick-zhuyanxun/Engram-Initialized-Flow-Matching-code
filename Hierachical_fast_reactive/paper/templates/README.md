# Paper Templates

This folder stores raw venue or institution templates. Templates are external
format sources, not manuscript drafts.

## Rules

- Keep raw template archives here.
- If a template is adapted into a real manuscript, create the manuscript under
  `paper/targets/<target>/`.
- Document any template changes in the target's `format_and_template_notes.md`.
- Do not put target-specific research text inside `templates/`.
