HFRVLA — Hierarchical Fast-Reactive VLA

A high-frequency wrist-camera correction module that closes the loop while the slow VLA thinks.

0 · The Problem We Solve

Core pain point

VLA models (SmolVLA, OpenVLA, π0) are powerful but too slow for closed-loop control. On consumer GPUs, a single chunk inference costs ≈ 100 ms+. During the open-loop execution of each chunk (~0.5 s), the arm is blind to perturbations — object shifts, contact transitions, and execution drift accumulate into failures.

Question: Can we add a tiny module that runs at every control step, uses only the wrist camera (no force/tactile), and decides when to correct the slow VLA's plan — without retraining the slow VLA?

4 · Action Merging — Where Two Loops Meet

δa_clip = clamp(δa, −δ_max, +δ_max) a_cand = a_base + g · δa_clip a_final = enforce_joint_velocity_limit(a_cand, prev_a, dt) └─ safety layer

Why a learned gate g?

Hard clipping treats every step identically. The gate g_t ∈ [0, 1] learns when correction is helpful — high during contact / alignment, low during stable transport.

supervised via G-C signal

Why "frozen" + "residual"?

SmolVLA stays untouched — its broad task knowledge is preserved. Only the small fast module is trained, on top of a base policy that already works. The gate then prevents over-correction on tasks the base policy handles well.

no SmolVLA retraining

5 · Training Signal — Three Losses

L_delta — supervise the residual

L_delta = || δa − (a_expert − a_base) ||²

Offline: run frozen SmolVLA over each LIBERO demo to get a_base per step; expert gives a_expert.

L_gate — supervise the gate (G-C: prediction improvement, stop-gradient on δa)

δ̄a = stop_grad(δa) g* = sigmoid( || a_expert − a_base ||² − || a_expert − (a_base + δ̄a) ||² ) ↑ "if adding δa actively reduces error, gate = 1" L_gate = BCE( g, g* )

Stop-gradient breaks the chicken-and-egg coupling. Gate becomes a trust estimator, not a magnitude detector.

L_contact — auxiliary contact-event head (training only)

L_contact = BCE( c, contact_label )

LIBERO: from MuJoCo contact tensor. Real robot: from joint torque heuristic. Dropped at inference.

L_total = L_delta + 1.0 · L_gate + 0.1 · L_contact

7 · Why this paper exists

1Confidence-gated visual residual on a frozen VLA. The gate is trained with a prediction-improvement signal — it learns when correction helps, not when correction is large.

2Task-conditioned spatial pooling (S-B). DINOv2 patch features + SmolVLA's z_goal/z_phase as cross-attention queries — semantic-aware visual servoing, not blind contact detection.

3Real-hardware demonstration on LeRobot SO-100 / SO-101. Three pre-committed tasks (grasp-and-place, peg insertion, push-to-target) with externally applied perturbations.

4Contact-event auxiliary supervision (training only). Multi-task regularization that teaches the GRU temporal state to differentiate transport vs contact phases.
