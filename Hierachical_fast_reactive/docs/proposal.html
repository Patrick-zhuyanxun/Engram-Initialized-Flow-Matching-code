Hierarchical Fast-Reactive VLA

Wrist-Camera-Based High-Frequency Residual Correction
for Closed-Loop Robot Manipulation

📁 Hierachical_fast_reactive 🧪 LIBERO Benchmark 🤖 SmolVLA + GRU Residual 📅 2026-05-11

1. Problem Statement

現代 Vision-Language-Action (VLA) 模型透過 action chunking 產生一段未來動作序列後，機械臂在執行這段 chunk 的過程中完全處於 開迴路（open-loop） 狀態——即使環境發生擾動、抓取位置偏移， 系統也無法即時修正，直到下一個 chunk 才能重新感知。

Core Pain Point

VLA 的 action chunk 執行期間缺乏內生的高頻回授機制（endogenous high-frequency feedback）。 即使加快 chunk 更新頻率，若沒有持續閉環修正，failure recovery 的成本仍會抵消速度增益。

現象

  • 抓取物體時因輕微位置偏移而失敗
  • 外力擾動後無法自行恢復
  • 末端執行器在接近階段產生誤差累積
  • 重試率高，整體任務成功率下降

文獻確認（2024–2026）

  • Yell At Your Robot（RSS 2024）：外部修正是長任務成功的關鍵
  • Realtime-VLA V2（arXiv:2603.26360）：failure recovery 抵消速度增益
  • RoboFAC（arXiv:2505.12224）：VLA 缺乏 failure-centric supervision
  • RL-for-VLA：compounding errors 在 distribution shift 下惡化

文獻綜述（2024–2026 年 VLA 生物啟發式運動控制分析）將「內生誤差驅動適應機制的缺失」 列為當前 VLA 長時程穩健行為的 第一大瓶頸。

Research Gap：目前沒有工作同時滿足「高頻視覺閉環 ＋ 語意感知 ＋ 通用硬體 ＋ 可插拔設計」。 Reactive Diffusion Policy 最接近，但需要觸覺感測器；AdaWorldPolicy 最完整，但需要 World Model。 本研究填補的是：只用機械臂已有的 wrist camera，就能做到語意感知的高頻殘差修正。

3. Proposed Solution — HFRVLA

Hierarchical Fast-Reactive VLA (HFRVLA)：在凍結的 Slow VLA 之上， 疊加一個以 wrist camera 為核心輸入的輕量 Fast Reactive Module， 以 30–60 Hz 高頻輸出殘差修正量，並透過 confidence gate 控制修正強度。

核心公式

a_final(t) = a_slow(t) + g_t · clip(δa_t, -δ_max, +δ_max)
δa_t, g_t = GRU( φ_wrist(I_t), s_t, a_slow(t), h_task ) h_task = VLM_encoder( instruction, global_obs ) ← frozen, detach()

4. Key Design Decisions

System 1 Backbone：GRU

30–60 Hz 串流推論需要 O(1) per-step 成本。GRU 隱藏狀態作為滑動時間視窗（10 steps = 167 ms），無需批次計算，可直接 ONNX/TensorRT 部署。Mamba 工程開銷過大，不適合第一篇論文。

低延遲 易部署 訓練穩定

訓練訊號：Offline Decomposition → Joint Fine-tune

Phase 1：Freeze SmolVLA，計算 δa = a_expert − a_slow 作為監督訊號，訓練 GRU residual 至收斂。Phase 2：Joint fine-tune slow + fast，讓特徵更協同。禁止直接監督 a_final（Option C），否則 gate 失去語意。

Phase 1 穩定 Phase 2 提升

Semantic-Aware Residual

System 1 以 h_task（SmolVLA VLM encoder 的 cross-attention fused feature）作為 task conditioning。這使殘差修正具語意感知——知道要抓什麼，才能決定如何修正，而非盲目視覺伺服。

語意感知 可解釋

Confidence Gate g_t

g_t ∈ [0,1] 學習何時要修正（接近物體、接觸前）、何時讓 System 2 主導（穩定移動段）。這是與 Reactive Diffusion Policy 的關鍵架構差異，防止 System 1 在穩定執行期間過度修正。

可消融測試 防過修正

5. 論文貢獻

🔌
可插拔設計（Plug-in）

不替代 VLA，不修改 SmolVLA 權重。可附加到任意 action-chunking VLA 上，降低採用門檻。

📷
視覺充分性（Vision-Sufficiency）

僅使用機械臂已有的 wrist camera（不需觸覺、力矩感測器），即可達到高頻閉環修正。降低硬體門檻，提高可部署性。

🧠
語意感知殘差（Semantic-Aware Residual）

透過 h_task conditioning，System 1 在修正動作時保有對任務目標的理解，而非純粹最小化視覺誤差。

🎛️
Confidence Gating

自適應控制 System 1 修正強度，在穩定段讓 System 2 主導，在接觸前啟動高頻修正。可透過消融實驗直接驗證。

6. Experiment Plan（LIBERO，IROS/ICRA 規模）

1
Main Result：SmolVLA alone vs. HFRVLA
LIBERO-Spatial + LIBERO-Goal 兩套件，各 10 tasks × 20 episodes。 主要指標：task success rate (%)。期望 +10–20% 提升。
Core
2
Perturbation Recovery Test
在 chunk 執行中途施加外力擾動（平移 ±2cm），測量恢復成功率與恢復時間。 這是最具說服力的實驗——審稿人無法以「只是調參」否定。
Core
3
Ablation：Gate Disabled (g=1)
移除 confidence gate，固定 g=1（總是修正）。 預期在精確抓取任務上因過度修正而性能下降，驗證 gate 的必要性。
Ablation
4
Ablation：w/o h_task Conditioning
移除 VLM 語意特徵輸入，System 1 僅使用 wrist visual + robot state。 驗證語意感知對殘差品質的貢獻。
Ablation
5
Baseline 比較：固定頻率 chunk 更新 (VLA + fast chunk refresh)
對比「提高 SmolVLA 更新頻率」而不加 residual module 的方案， 顯示殘差修正比單純加快 chunk refresh 更有效且計算成本更低。

8. Reviewer Defense

Q：這只是 Reactive Diffusion Policy 換感測器？

RDP 需要觸覺感測器（特殊硬體，多數機械臂沒有）。我們的貢獻是： 普通 wrist camera 已足夠做高頻閉環修正，改變部署門檻， 不是感測器替換。此外，RDP 沒有 confidence gate——我們的 g_t 是獨立的可測試設計。

Q：跟 Hi Robot 的分層有何差異？

Hi Robot 的 System 1 沒有視覺閉環，它的「快」只是更快地輸出動作， 而非持續感知修正。我們的 System 1 以 30–60 Hz 真正做觀測驅動的殘差修正， 屬於 motor-level hierarchy 而非 planning-level hierarchy。

Q：pure 視覺伺服（visual servoing）就夠了？

純視覺伺服不具語意感知，無法知道要抓哪個物體。 我們的 h_task conditioning 讓 System 1 在多物體場景中仍能做出正確的方向性修正。

Q：模擬結果能泛化到真機嗎？

IROS/ICRA 接受純模擬結果（LIBERO 為 accepted benchmark）。 論文中可說明 sim-to-real 的主要挑戰在 wrist camera 影像品質， 並以 plug-in 設計作為未來真機驗證的基礎。
